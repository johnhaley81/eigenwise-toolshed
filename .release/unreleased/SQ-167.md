---
ref: SQ-167
title: Quartermaster update reminders follow the registered marketplace source
bump: patch
plugins: [quartermaster]
---

The prompt and Stop update reminders compared installed plugin versions against the upstream `main` manifest, even after `eigenwise-toolshed` was repointed to a fork. A fork release then showed no reminder, and an upstream release above the fork showed one that `/update-toolshed` could not satisfy. The manifest URL now comes from the `eigenwise-toolshed` entry in `~/.claude/plugins/known_marketplaces.json`: a `github` source with its `ref`, or a `git` source on github.com. Any other source, or a missing or unreadable registry, keeps the upstream URL. The freshness cache records that URL, and a cache written for a different URL is ignored, so a repoint takes effect on the next hook run.
